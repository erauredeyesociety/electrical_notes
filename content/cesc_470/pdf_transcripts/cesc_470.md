Detailed exploration of Von Neuman computer architecture, including
processors, memory, input/output, machine language, assembly language,

architecture design, learning key concepts like instruction sets, memory
hierarchy, and pipelining.

Student Learning Outcomes
1. Evaluate the principles and trade-offs (cost/performance,
speed/flexibility) behind the design of modern computer systems,
using both qualitative and quantitative methods.
2. Design an instruction set for a specific processor architecture,
considering factors such as complexity, performance, and flexibility.
3. Analyze hierarchical memory system designs, including cache
performance and optimization strategies, to improve system
efficiency.
4. Optimize processor performance using applicable concepts of
basic and advanced pipelining techniques.
5. Assess the advantages and limitations of hardwired and
microprogrammed control mechanisms in modern computer
architectures.
6. Explain how the architecture of multicore processors improves
parallelism and system throughput.

Weather Emergency Statement
Hurricanes, tornadoes and other natural disasters (such as fires) are a
