\section*{Problem}
Describe how increasing confidence level, sample size, or population standard deviation changes the width of a confidence interval.
\section*{Work}
For a mean with known $\sigma$, the margin of error is
\[
E=z_{\alpha/2}\frac{\sigma}{\sqrt n}.
\]
Increasing confidence increases $z_{\alpha/2}$, so the interval gets wider. Increasing $n$ increases the denominator, so the interval gets narrower. Increasing $\sigma$ increases the numerator, so the interval gets wider.
\finalanswer{(a) increases; (b) decreases; (c) increases.}
