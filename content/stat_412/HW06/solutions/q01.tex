\section*{Problem}
Use the number line values $\mu=24.88$ and $\bar x=26.23$ to find the sampling error.
\section*{Work}
Sampling error is sample statistic minus population parameter:
\[
\bar x-\mu=26.23-24.88=1.35.
\]
\finalanswer{$1.35$}
