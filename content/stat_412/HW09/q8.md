# Question 8

In a randomized controlled trial, insecticide-treated bednets were tested as a way to reduce malaria. Among 334 infants using bednets, 15 developed malaria. Among 276 infants not using bednets, 27 developed malaria. Use a 0.05 significance level to test the claim that the incidence of malaria is lower for infants using bednets.

Let infants using bednets be population 1 and infants not using bednets be population 2.

Complete parts (a) through (c).

## Part (a)

Test the claim using a hypothesis test.

Hypothesis choice: **E**.

- \(H_0:p_1=p_2\)
- \(H_a:p_1<p_2\)

\[
\hat p_1=\frac{15}{334}=0.0449,\qquad
\hat p_2=\frac{27}{276}=0.0978.
\]

\[
z=-2.57,\qquad p=0.0051.
\]

Reject \(H_0\). There is sufficient evidence that the malaria incidence rate is lower for infants using bednets.

## Part (b)

Using the confidence-interval approach, an appropriate 90% confidence interval for \(p_1-p_2\) is

\[
-0.0877 < p_1-p_2 < -0.0181.
\]

The entire interval is below 0, supporting \(p_1<p_2\).

## Part (c)

Yes. The hypothesis test and confidence interval both suggest that bednets are effective in reducing malaria incidence.

- According to the hypothesis test, there is **sufficient** evidence, so the bednets **appear** to be effective.
- According to the confidence interval, there is **sufficient** evidence, so the bednets **appear** to be effective.

Detailed completed sentence: According to the hypothesis test, there is **sufficient** evidence to support the claim that the incidence of malaria is lower for infants using bednets, so the bednets **appear** to be effective. According to the confidence interval, there is **sufficient** evidence to support the same claim because the interval is entirely below 0, so the bednets **appear** to be effective.

## Platform conclusion

- Dropdown options: **greater than** / **less than**. Select **less than**.
- Dropdown options: **reject** / **fail to reject**. Select **reject**.
- Completed sentence: Since the P-value is **less than** the significance level \(\alpha=0.05\), **reject** the null hypothesis.
- Final wording: There is sufficient evidence that infants using bednets have a lower malaria incidence rate.

- Completed sentence: Since the confidence interval **does not contain** zero, there **appears** to be a difference between the proportions.
