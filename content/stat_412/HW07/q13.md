# Question 13

One research study of illegal drug use among 12- to 17-year-olds reported a decrease in use from 11.4% in 1997 to 9.7% now. Suppose a survey in a large high school reveals that, in a random sample of 1,050 students, 99 report using illegal drugs. Use a 0.05 significance level to test the principal's claim that illegal drug use in her school is below the current national average.

Formulate the null and alternative hypotheses.

Choices:

- A. \(H_0:p<0.097,\ H_a:p=0.097\)
- B. \(H_0:p=0.097,\ H_a:p>0.097\)
- C. \(H_0:p=0.097,\ H_a:p\ne0.097\)
- D. \(H_0:p=0.097,\ H_a:p<0.097\)

## Cleaned / corrected parts

The claim is **below** the current national average, so this is a left-tailed test.

- Correct choice: **D**
- \(H_0:p=0.097\)
- \(H_a:p<0.097\)

The sample proportion is
\[
\hat{p}=\frac{99}{1050}\approx 0.0942857.
\]

Using the exact sample proportion, the standard one-proportion z statistic is
\[
z=\frac{\hat{p}-p_0}{\sqrt{p_0(1-p_0)/n}}
  =\frac{0.0942857-0.097}{\sqrt{0.097(0.903)/1050}}
  \approx -0.29718,
\]
which rounds to **-0.30**.

However, if the platform first asks for \(\hat p\) rounded to three decimals and then uses that rounded value, \(\hat p=0.094\), then
\[
z=\frac{0.094-0.097}{\sqrt{0.097(0.903)/1050}}
  \approx -0.32846,
\]
which rounds to **-0.33**.

Use **-0.33** if the platform rejected **-0.30** for the z statistic. The sign must be negative either way because the sample proportion is below 0.097.

The left-tail P-value is about \(0.383\) using the exact statistic, or about \(0.371\) using the rounded-proportion statistic. Either way, do not reject \(H_0\). There is not enough evidence that the school’s illegal drug use rate is below the current national average.
