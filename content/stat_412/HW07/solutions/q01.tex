\section*{STAT 412 HW07 --- Question 1}

\subsection*{Problem}

\begin{quote}
Suppose that an allergist wishes to test the hypothesis that at least 31\% of the public is allergic to some cheese products. Explain how the allergist could commit a type I error and a type II error.
\end{quote}

\subsection*{Solution}

The claim is ``at least 31\%,'' so put that in the null hypothesis:
\[
H_0:p\ge0.31,\qquad H_a:p<0.31.
\]

A type I error rejects a true null hypothesis. Here, that means concluding the alternative-side statement when the null-side statement is actually true:

\[
\text{conclude }p<0.31\quad\text{when actually }p\ge0.31.
\]

A type II error fails to reject a false null hypothesis. In the platform wording, this is phrased as concluding the null-side statement when the alternative-side statement is actually true:
\[
\text{conclude }p\ge0.31\quad\text{when actually }p<0.31.
\]

\subsection*{Final Answer}

\fbox{\begin{minipage}{0.94\linewidth}
Type I: conclude less than 31\% are allergic when actually 31\% or more are allergic. Type II: conclude 31\% or more are allergic when actually less than 31\% are allergic.
\end{minipage}}
