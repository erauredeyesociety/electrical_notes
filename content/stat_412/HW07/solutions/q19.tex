\section*{STAT 412 HW07 --- Question 19}

\subsection*{Problem}

\begin{quote}
What is a type I error? What is a type II error?

Choose the correct answer.

A. A type I error is the mistake of failing to reject the null hypothesis when the null hypothesis is actually true. A type II error is the mistake of rejecting the null hypothesis when the null hypothesis is actually false.

B. A type I error is the mistake of rejecting the null hypothesis when the null hypothesis is actually false. A type II error is the mistake of failing to reject the null hypothesis when the null hypothesis is actually true.

C. A type I error is the mistake of rejecting the null hypothesis when the null hypothesis is actually true. A type II error is the mistake of failing to reject the null hypothesis when the null hypothesis is actually false.

D. A type I error is the mistake of failing to reject the null hypothesis when the null hypothesis is actually false. A type II error is the mistake of rejecting the null hypothesis when the null hypothesis is actually true.
\end{quote}

\subsection*{Solution}

Type I error means rejecting a true null hypothesis. Type II error means failing to reject a false null hypothesis.

\subsection*{Final Answer}

\fbox{\begin{minipage}{0.94\linewidth}
Choice C.
\end{minipage}}
