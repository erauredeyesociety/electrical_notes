\section*{STAT 412 HW07 --- Question 7}

\subsection*{Problem}

\begin{quote}
The average height of females in the freshman class of a certain college has historically been 162.2 centimeters with a standard deviation of 7.2 centimeters. How large a sample is required to test whether the average height has changed for the present freshman class if the power of the test is to be 0.95 when the true average height differs from 162.2 centimeters by 3.3 centimeters? Use alpha = 0.2.

Find the minimum sample size required. Round up to the nearest whole number.
\end{quote}

\subsection*{Solution}

For a two-sided z test with alpha=0.20 and power=0.95, use z\_(1-alpha/2)=z\_0.90=1.2816 and z\_power=z\_0.95=1.6449. n=[(1.2816+1.6449)(7.2)/3.3]\textasciicircum{}2=40.77, so round up to 41.

\subsection*{Final Answer}

\fbox{\begin{minipage}{0.94\linewidth}
Minimum sample size n=41.
\end{minipage}}
