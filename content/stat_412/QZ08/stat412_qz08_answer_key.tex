\section*{STAT 412 QZ08 --- Concise Answer Key}
\begin{enumerate}[label=\textbf{\arabic*.}]
\item Births: \(H_0\): equal frequencies by weekday. \(H_1\): not equal frequencies by weekday. \(\chi^2=11.941\), \(df=6\), \(p=0.0633\). Conclusion C; explanation A.
\item Heights GOF: expected table row \(33.17,43.95,41.91,27.97\). Choice D. \(H_0\): observed equals expected in every class. \(H_1\): at least one class differs. \(\chi^2=1.02\), \(p=0.314\). Fail to reject.
\item Games GOF: expected counts \(11.875,23.750,29.688,29.688\). \(H_0\): actual counts fit expected proportions. \(H_1\): not fit. \(\chi^2=10.011\), \(p=0.0185\). Choice C.
\item Post positions: expected count \(11.5\) in each position. \(H_0\): same winning likelihood. \(H_1\): not the same. \(\chi^2=12.043\), \(p=0.2109\). Choice A; bettors: No.
\item Candy/tips: choice C, \(H_0:\mu_1=\mu_2\), \(H_1:\mu_1<\mu_2\). \(t=-4.42\), \(p=0.000\). Choice C. CI blanks: \(-3.78,-1.10\).
\item Polygraph: expected table rows \(17.6,46.4\) and \(4.4,11.6\). Choice A. \(H_0\): independent. \(H_1\): not independent. \(\chi^2=2.649\), \(p=0.1036\). Final D/no.
\item Eye color: expected rows male \(329.97,286.09,142.82,153.12\); female \(407.03,352.91,176.18,188.88\). Choice C. \(\chi^2=12.67\), \(p=0.005\). Conclusion C.
\item Tire: \(H_0:\mu_1-\mu_2=0\), \(H_1:\mu_1-\mu_2\ne0\). \(t=-0.90\), \(df=22\), \(p=0.380\). Range \(0.3<P<0.4\). Do not reject.
\item Treatment/placebo: choice B, \(H_0:\mu_1=\mu_2\), \(H_1:\mu_1\ne\mu_2\). \(t=-1.68\), \(p=0.098\). Choice C. CI blanks: \(-0.775,0.175\).
\item Tennis: expected rows men \(292.556,683.444\); women \(427.444,998.556\). Choice B. \(H_0\): independent. \(H_1\): not independent. \(\chi^2=10.988\), \(p=0.0009\). Conclusion B.
\end{enumerate}
