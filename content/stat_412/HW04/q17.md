# Question 17

Given a random variable \(X\), with standard deviation \(\sigma_X\), and a random
variable \(Y=a+bX\), show that if \(b<0\), the correlation coefficient
\(\rho_{XY}=-1\), and if \(b>0\), \(\rho_{XY}=1\).

The equation for the correlation coefficient of \(X\) and \(Y\) is
\(\rho_{XY}=\dfrac{b}{|b|}\). *(Select from the dropdown; the field was still
empty.)*

Because \(\operatorname{Cov}(X,a+bX)=b\,\sigma_X^2\) and
\(\sigma_Y=|b|\,\sigma_X\), we get
\(\rho_{XY}=\dfrac{b\,\sigma_X^2}{\sigma_X\cdot|b|\sigma_X}=\dfrac{b}{|b|}\),
which is \(+1\) for \(b>0\) and \(-1\) for \(b<0\).
