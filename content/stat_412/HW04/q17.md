# Question 17

Given \(Y=a+bX\), show that \(\rho_{XY}=-1\) for \(b<0\) and
\(\rho_{XY}=1\) for \(b>0\).

## Exact platform responses

Enter or select the following in order:

   \[
   \boxed{\frac{\sigma_{XY}}{\sigma_X\sigma_Y}}
   \]

2. Covariance:
   \[
   \boxed{E[(X-\mu_X)(Y-\mu_Y)]}
   \]

3. After substituting \(Y=a+bX\):
   \[
   \boxed{b\sigma_X^2}
   \]

4. Standard deviation of \(Y\):
   \[
   \boxed{\sqrt{b^2\sigma_X^2}}
   \]

5. Select **Choice A**:
   \[
   \boxed{\rho_{XY}=\frac{b}{|b|}}.
   \]

6. Complete the final sign dropdowns:

   - If \(b>0\), select **positive** for the numerator and **positive** for

## Complete derivation

Start with

\[
\rho_{XY}=\frac{\sigma_{XY}}{\sigma_X\sigma_Y}.
\]

Since \(Y=a+bX\),

\[
\begin{aligned}
\sigma_{XY}
&=\operatorname{Cov}(X,a+bX)\\
&=\operatorname{Cov}(X,a)+b\operatorname{Cov}(X,X)\\
&=0+b\operatorname{Var}(X)\\
&=b\sigma_X^2.
\end{aligned}
\]

Also,

\[
\operatorname{Var}(Y)
=\operatorname{Var}(a+bX)
=b^2\sigma_X^2,
\]

so

\[
\sigma_Y
=\sqrt{\operatorname{Var}(Y)}
=\sqrt{b^2\sigma_X^2}
=|b|\sigma_X.
\]

Substituting gives

\[
\rho_{XY}
=\frac{b\sigma_X^2}{\sigma_X(|b|\sigma_X)}
=\frac{b}{|b|}.
\]

When \(b<0\), the numerator \(b\) is negative and the denominator \(|b|\) is
positive, so

\[
\rho_{XY}=-1.
\]

When \(b>0\), both \(b\) and \(|b|\) are positive, so

\[
\rho_{XY}=1.
\]
