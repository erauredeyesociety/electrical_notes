# Question 11

Let \(X\) represent the number that occurs when an 8-sided red die is tossed and
\(Y\) the number that occurs when an 8-sided green die is tossed. Complete parts
(a) and (b) below.

(a) Find the variance of the random variable \(4X-Y\). →
\(16(5.25)+5.25=89.25\).

(b) Find the variance of the random variable \(X+3Y-5\). →
\(\operatorname{Var}(X)+9\operatorname{Var}(Y)=5.25+9(5.25)=52.5\).

*(Simplify your answers.)* Each die is uniform on \(1,\dots,8\), so
\(\operatorname{Var}=\dfrac{8^2-1}{12}=5.25\); the additive constant \(-5\) does
not affect variance.
