# Question 17

Observed homicide counts by month:

| Month | Number |
|---|---:|
| January | 39 |
| February | 31 |
| March | 45 |
| April | 39 |
| May | 47 |
| June | 50 |
| July | 48 |
| August | 50 |
| September | 50 |
| October | 42 |
| November | 38 |
| December | 38 |

Test whether homicides are uniformly distributed across months.

## Solution

- \(H_0\): homicides are uniformly distributed across the months.
- \(H_1\): homicides are not uniformly distributed across the months.
- Total \(n=517\); expected count per month \(=517/12=43.0833\).
- Test statistic: \(\chi^2=9.72\).
- P-value: \(0.555\).
- Conclusion: do not reject \(H_0\). There is not sufficient evidence that homicides occur more often in some months than others.
