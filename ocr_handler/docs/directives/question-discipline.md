# Question Discipline

**WHEN** you hit a call only the operator can make → **DON'T** guess it, and **DON'T** drip it →
**BECAUSE** a guessed scope answer costs a rewrite, and one-question-at-a-time forces babysitting.

- **The open questions are already enumerated** in [../scope.md](../scope.md) § Open decisions (six) and
  [../plans/text-layer-first.md](../plans/text-layer-first.md) § 10 (six more). Read ahead and **ask them
  in one round**, each led by a recommendation and a default so it is a one-tap approval.
- **Highest-impact first:** output destination · the 400-char `sparse` gate · non-PDF inputs. Those three
  change what gets built. The rest change values.
- **Proceed on a defensible default; ask only when the answer changes the outcome.** `--mode` defaulting
  to `text` needs no approval — it is the cheap, safe behaviour. Where output lands does, because it
  writes to the operator's filesystem.
- **"Defer until X" is a command, not a dismissal.** Record the re-raise trigger in `todo.md` and carry it
  forward.
- **Halt only the blocked item.** The engine question blocks `recognize.py`; it blocks nothing in M2. Keep
  the extractor moving.
- **Git is human-only.** Every commit, push, checkout, add or hook installation is proposed as a command
  for the operator to run — never executed.
